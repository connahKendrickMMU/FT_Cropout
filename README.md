# FT_Cropout
A Blueprint demo of Unreals Cropout Game
## Controls
- WASD or Arrow keys to move the Camera
- Q & E rotate the Camera
- Wheel to Zoom
- Left mouse to select
- To assign a villeger click and drag to a resource
- Then use the build menu to build new features.
## Overview 
This is an example that was built to show how a full Blueprint project in unreal could be built and optimised to a good standard, that has features or a standard base builder. This will serve us well to show how we can optimise the game even furthr through the use of C++.

## Task 
- Play the game, understand its functionality and construction
- Convert the Blueprints to C++
This is to build a needed skill set as studio must convert legacy games/ current projects to the new C++ systems.

## Challenges
Test your might

### Easy 
- Convert the [project to a C++ project](https://mmutube.mmu.ac.uk/media/Adding+CPP+to+a+Blueprint+project/1_3nrfhm9e)
- Reparent a [Blueprint Class with a C++](https://mmutube.mmu.ac.uk/media/Reparenting+a+Blueprint/1_3quij84e)
- Convert a Variable from Blueprint to C++

### Medium
- Start deleting old Blueprint Variables and Function checkingt he game still runs
- Use the UProperties/ UFunctions to properly Expose varables and functions to the blueprint
- Try a full conversion of a single function from blueprint to C++

### Hard 
- Convert a full blueprint object to C++ 
- See if you can further optimise the code one it is in C++ 
- Try comparing performance before and after with the [unreal profiler](https://dev.epicgames.com/community/learning/tutorials/k8pB/unreal-engine-performance-profiling-and-debugging)

### Coding Standards
Try in your conversion to follow the [unreal standard](https://dev.epicgames.com/documentation/unreal-engine/epic-cplusplus-coding-standard-for-unreal-engine?lang=en-US).
